# PyTorch Neural Networks Course Projects

Projects from Udacity's **Introduction to Neural Networks with PyTorch** course (AWS AI & ML Scholars Certificate).

## Date
Completed: 2023

## Structure
- deep-learning-with-pytorch/ - Core course with 8 parts covering tensors, neural networks, training, Fashion-MNIST, inference, saving/loading, image data loading, and transfer learning. Each part has Exercise and Solution notebooks.
- gradient-descent/ - Gradient descent implementation with visualization (GradientDescent.ipynb, GradientDescentSolution.ipynb)
- student-admissions/ - Neural network for predicting student admissions (StudentAdmissions.ipynb with student_data.csv)

## Requirements
- Python 3, PyTorch, torchvision, numpy, pandas, matplotlib, scikit-learn

## How to Run
Open any .ipynb in Jupyter Notebook/Lab. Start with the Exercise notebooks in deep-learning-with-pytorch/ for the learning path.
